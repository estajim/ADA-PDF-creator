# Minimal requirements for PyInstaller desktop build.
# Heavy ML packages (PyTorch, Surya, BLIP, docling) are EXCLUDED from the bundle
# because PyInstaller cannot analyse them in a reasonable time and they are
# downloaded on first run anyway via the model-download step.
#
# OCR falls back to pytesseract (lighter, bundled Tesseract binary).
# Alt-text generation is skipped unless the user enables it via ANTHROPIC_API_KEY.

# Settings
